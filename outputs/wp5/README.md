# WP5 results

The seed-42 run used 9,010 WP1 gold training records, 3,968 untrusted records and 1,642 fold-9 validation records. Raw PTB-XL metadata confirmed that the 3,968 pool records had autogenerated initial reports and lacked human validation.

- **Discard vs. correct.** EM achieved the highest validation macro F1 in all 20 cells (0.4111 to 0.4623). Each gold fraction is a stratified fraction of the available WP1 gold set. Corruption is additional to any existing pool label noise. GraphLP and CoTraining discard pool labels, so their scores are constant across corruption rates for a given gold subset. All 20 EM fits reached the 30-iteration cap before meeting tolerance.
- **Annotator audit.** The audit met tolerance at iteration 39. The largest estimated off-diagonal transitions were NORM to MI (9.41%), STTC to MI (9.18%) and HYP to NORM (6.19%). These are latent-model estimates on unvalidated reports.
- **Synthetic recovery.** With 500 gold examples, Frobenius error fell from 0.364 at pool size 100 to 0.145 at 5,000. It was lowest at 2,000 (0.135). The two largest fits reached their 50-iteration cap.

To reproduce from the repository root, substitute the local metadata path and run:

```sh
python wp5_latent_noise_em/run_wp5.py --features_path outputs/wp1/features.npz --labels_path outputs/wp1/labels.npz --meta_path "/path/to/ptbxl_database.csv" --out_dir outputs/wp5
```
